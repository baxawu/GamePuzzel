# Unlock The World Steel

Game "Unlock The Picture" tương tác — giải 14 câu đố để mở khóa bức hình tổng thể công ty.

## Chạy local
Mở trực tiếp file `index.html` bằng trình duyệt.

## Deploy
Project này là 1 file HTML tĩnh, không cần build step. Deploy trực tiếp lên Vercel/Netlify/GitHub Pages đều được.
